02 / Craft

One practice. Several mediums.

Strong products are rarely just code or just visuals. They are systems of decisions, so I move between the layers.

  1. 01

    Product engineering

    From a useful premise to a working, deployed product. Explicit user flows, careful data boundaries, and deployment treated as part of the design.

    React / TypeScript / Python / APIs
  2. 02

    Systems

    Tools close to the machine. Linux environments, terminal software, small servers, networking, and embedded experiments.

    Linux / Docker / C++ / CLI
  3. 03

    Interface craft

    Clear hierarchy with a pulse. Responsive, keyboard-friendly experiences with motion that supports understanding.

    HTML / CSS / JavaScript / Accessibility
  4. 04

    Visual stories

    Cinematic video edits and visual references. The same eye for pacing and framing ends up in the interfaces I build.

    Editing / Motion / Framing
“Structure first. Character second. Polish all the way through.”
  1. FrameFind the real problem and who it is for.
  2. PrototypeMake the rough version fast and honest.
  3. BuildShip it with real data and real edges.
  4. RefineFix where it breaks until it feels inevitable.

03 / About

Curious enough to cross disciplines. Serious enough to finish.

I’m a student and independent builder. I learn fastest by making real things, finding where they break, and refining them until the interaction feels inevitable.

My work moves between full-stack software, developer tools, self-hosted infrastructure, embedded hardware, interface design, and cinematic video editing. Most of it lives on GitHub, and the rest ends up on YouTube.
