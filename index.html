03 / Process

A small system for making things hold together.

I use the same sequence whether I am shaping a product flow, a terminal tool, or a visual interface.

  1. 01

    Find the real constraint

    Start with the user, environment, and failure cases. A smaller honest problem is more useful than a broad imaginary one.

  2. 02

    Build the plain version

    Establish content, data flow, responsive structure, and keyboard behavior before adding visual personality.

  3. 03

    Add a point of view

    Use typography, geometry, and motion to clarify relationships and pacing rather than to cover weak structure.

  4. 04

    Test the edges

    Check narrow screens, reduced motion, broken links, empty states, and the path a first-time visitor is likely to take.
